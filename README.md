# Focus Hub

Focus Hub is a React-based student productivity website designed to help students organize their study activities and stay focused.

## Features

- Student dashboard
- Study task management
- Focus timer
- Progress tracking
- Responsive design
- Modern user interface
- React components
- CSS styling

## Technologies Used

- React
- JavaScript
- HTML
- CSS
- Vite

## Installation

1. Clone or download the project.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Install dependencies:
